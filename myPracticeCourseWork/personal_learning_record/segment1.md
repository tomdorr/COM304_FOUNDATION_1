**Short history of computing**

We looked at the evolution of computers, first looking at mechanical calculators and how they work.

Mechanic calculators perform arithmetic operations using gears, levers and dials.

We then looked at mechanical computers which unlike mechanical calculators could perform sequences of operations and could be programmed in limited ways.

## session 2
We started this session with an overview of computing architectures followed by how Boolean logic in logic gates can be used to do binary arithmetic. Once we had a basic understanding we furthered our learning by by looking how using complex combination logic of the logic gates can create a CPU.

**Computer architecture**

We looked at two computing architecture theory’s – Turing machine and von Neumann architecture.

A **Turing machine** is a theoretical model that defines a simple, but powerful, way of describing computation. This link helps to explain how the concept works as well as its importance in computing: <https://www.geeksforgeeks.org/turing-machine-in-toc/>

Von Neumann architecture

This is the architecture used by most computers today. The **Von Neumann architecture** is a computer design model where a CPU executes instructions stored in memory, using a unified memory space for both data and instructions. I found this website useful to understand this concept as it breaks it down simply while still explaining the complexity of it: <https://www.studysmarter.co.uk/explanations/computer-science/computer-organisation-and-architecture/von-neumann-architecture/>

**Types of memory**

Each type of memory serves a specific role in a computer system, balancing between speed, capacity, and volatility: <https://www.techtarget.com/whatis/definition/memory>

**X86 vs ARM architecture**

\- x86 is ideal for high-performance, general-purpose computing, especially in desktops, laptops, and servers where raw power and extensive software compatibility are required.

\- ARM excels in power efficiency, making it the architecture of choice for mobile devices, embedded systems, and increasingly, for high-performance computing

**Binary arithmetic**

We looked at why binary arithmetic is essential for computers. It involves adding, subtracting, dividing, multiplying and handling negative numbers using techniques like twos compliment.

<https://www.studysmarter.co.uk/explanations/computer-science/data-representation-in-computer-science/binary-arithmetic/> helped me to understand and practise these operations. We used a hex calculator and Cisco binary game which I found as I fun way to further my ability and knowledge.

**Boolean algebra and logic gates**

Next in the lesson we looked at logic gates and how they can be combined to create complex circuits.

And – output 1 if both inputs are 1

Or – outputs 1 if at least one input is 1

Not – inverts the input

XOR – outputs 1 if inputs are different otherwise 0

NAND – output is 0 if both inputs are 1

**4 bit computing**

We used this knowledge to create a simple processor using a 4 bit program.

The simulator gave me a better understanding of how a cpu works by seeing it on a smaller scale.

This understanding was further developed by looking at the more complex cpu example:
