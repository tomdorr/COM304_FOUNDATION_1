## session 9
In this session I looked at what networking is, how computers communicate through networks.

**Internet protocol**

Computers and routers are key devices in a network - modern computers use the IP to to divide data into packets, these packets are sent separately across a network via routers and reassembled at the destination.

Domestic gateway routers connect to a core provider network to transfer data between different networks.

**Network protocol layers**

The TCP/IP model(4 layers and foundation of the internet) is a more simplified version of the OSI model(7 layers) and is used in most practical networking systems, including the Internet. 
I found this website useful to understand the differences between them and how each of them work with the tables/diagrams: 
<https://www.geeksforgeeks.org/difference-between-osi-model-and-tcp-ip-model/>
